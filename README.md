# Random Pop Culture

Une page qui tire au hasard un personnage de pop culture (jeux vidéo, films, séries, anime, super-héros, musique, memes… 141 au total) et affiche son résumé, récupéré en direct sur Wikipédia.

## Utilisation

Tout tient dans `index.html`, sans dépendance ni build :

- ouvrir le fichier dans un navigateur, ou
- le servir avec n'importe quel serveur web statique.

Une connexion internet est nécessaire pour interroger l'API de Wikipédia.
